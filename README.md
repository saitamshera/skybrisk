# Skybrisk

Month-wise record of my Data Science internship work: Python fundamentals, data analysis, visualization, and applied projects on real datasets.

The repository is organized by month so the progression is easy to follow.

## Repository structure

```
skybrisk/
├── Month 1/
│   ├── w-1/   week1_python_basics.py
│   ├── w-2/   week2_data_structures_functions.py
│   ├── w-3/   week3_numpy_pandas.py + iris datasets
│   ├── w-4/   week4_visualization.py + plots/
│   └── README.md
│
├── Month 2/
│   ├── comparison/
│   ├── data/          (raw/ and processed/)
│   ├── task3_churn/
│   ├── task4_netflix/
│   ├── build_notebooks.sh
│   ├── requirements.txt
│   └── README.md
│
└── README.md
```

## Month 1: Python and data science foundations

| Folder | Focus |
|---|---|
| `w-1/` | Python basics |
| `w-2/` | Data structures and functions |
| `w-3/` | NumPy and Pandas, Iris dataset cleaning and species summary |
| `w-4/` | Data visualization (line, bar, pie, heatmap, pairplot, boxplot, dashboard) |

## Month 2: Applied data science projects

| Project | What it covers | Location |
|---|---|---|
| Customer churn | Which telecom customer groups are more likely to leave | `Month 2/task3_churn/` |
| Netflix catalogue | Content trends, genres, countries, and a simple forecast | `Month 2/task4_netflix/` |

See [`Month 2/README.md`](Month%202/README.md) for the deliverables table and setup steps.

## Getting started

```bash
git clone https://github.com/saitamshera/skybrisk.git
cd skybrisk
```

1. Start with `Month 1/` for the foundations.
2. For `Month 2/`, install dependencies with `pip install -r "Month 2/requirements.txt"`, then open the notebooks in Jupyter.
